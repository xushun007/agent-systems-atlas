# Coding Agent 的 Agent State：状态分类、所有权与派生关系

## 专题问题

本专题研究 Coding Agent 的状态由哪些部分组成，以及这些状态由谁拥有、谁可以修改、如何持久化、如何恢复和如何投影给模型与用户。

重点区分：

- 事实状态；
- 控制状态；
- 任务与计划状态；
- Environment 外部状态；
- Capability、Authority 和协调状态；
- Provider Runtime 状态；
- Context、UI、Trace 等派生状态。
