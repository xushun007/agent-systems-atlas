# Coding Agent 的 Planning 与 Task Decomposition

## 专题问题

本专题研究 Coding Agent 如何把用户目标和模型计划转化为可执行、可观察、可修正、可恢复的任务结构。

重点区分：

- 用户 Intent；
- 模型提出的自然语言计划；
- Runtime 接受的结构化工作项；
- Step 序列；
- Tool Call 与 Observation；
- 子 Agent 和后台任务；
- 计划状态与实际执行轨迹。
