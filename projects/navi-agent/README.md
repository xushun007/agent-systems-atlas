# Navi Agent

本项目研究 Navi Agent `v0.1.0` 的 Runtime/Harness 设计。

- 上游仓库：[xushun007/navi-agent](https://github.com/xushun007/navi-agent)
- 分析版本：`v0.1.0`
- 分析 commit：[`0e50b0a61f695d7843c9f75d9a72a6d79a7a2c46`](https://github.com/xushun007/navi-agent/commit/0e50b0a61f695d7843c9f75d9a72a6d79a7a2c46)
- 研究报告：[Navi Agent v0.1 Harness Runtime 分析](research/navi-agent-v0.1-harness.md)

本报告严格限定为 v0.1.0 快照，不描述项目整体历史。研究重点是 ApplicationService、AgentRuntime、Session/Run/Iteration、Tool Policy/Approval、RuntimeEvent、Background Task、Environment 与 Evolution side plane。
