2. Hooks & Extension Points

beforeToolCall()
  • Validate arguments
  • Block execution → { block: true, reason }
  • Honor abort signal
afterToolCall()
  • Override content
  • Override details
  • Set terminate hint
  • Set error flag
prepareNextTurn()
  • Swap context
  • Change model mid-run
  • Adjust thinking level
shouldStopAfterTurn()
  • Graceful stop hint
  • Before context gets too full
  • Skip follow-up polling
convertToLlm()
  • AgentMessage[] → Message[]
  • Filter UI-only messages
  • Map custom message types
transformContext()
  • Prune old messages
  • Inject external context
  • Run before convertToLlm
getApiKey()
  • Dynamic key resolution
  • Short-lived OAuth tokens
  • Per-call key rotation

3. Lifecycle Events

agent_start Run begins
turn_start New turn (assistant response + tool calls)
message_start (user) Prompt injected
message_end (user)
message_start (assistant) Streaming begins
message_update × N text_delta / thinking_delta / toolcall_delta
message_end (assistant) Final assistant message
tool_execution_start Per tool call
tool_execution_update × N Optional partial progress
tool_execution_end Result ready
turn_end message + toolResults[]
agent_end Run complete — messages[] returned, listeners awaited

4. Tool Execution Modes

Sequential
① prepare → ② execute → ③ finalize
① prepare → ② execute → ③ finalize
① prepare → ② execute → ③ finalize
Each tool call fully completes before the next starts
Parallel (default)
Preflight: prepare all sequentially
Execute: allowed tools run concurrently
emit end: in tool completion order
emit results: in assistant source order
AgentTool Interface
  • name, label, description — metadata
  • parameters — TypeBox schema for validation
  • prepareArguments?(args) — compatibility shim
  • execute(id, params, signal, onUpdate) → AgentToolResult
  • executionMode? — per-tool override ("sequential" | "parallel")

6. Package Structure

File Component Responsibility
agent.ts Agent class Stateful wrapper: transcript, tools, model, queues, lifecycle, AbortController
agent-loop.ts runAgentLoop Pure function loop: AgentMessage throughout, tool execution, LLM call boundary conversion
proxy.ts streamProxy HTTP SSE proxy: POST /api/stream, client-side partial reconstruction
types.ts Type definitions AgentMessage, AgentEvent, AgentTool, AgentLoopConfig, hooks, queues
harness/compaction/ Compaction Context window management: branch summarization, token estimation, cut-point finding
harness/session/ Session Conversation persistence: JSONL repo, memory storage, UUID v7
harness/skills.ts Skills Skill loading and management for agent prompts
harness/system-prompt.ts System Prompt System prompt template generation
